¿Que es un encapsulamiento?

El encapsulamiento (o ocultamiento de información) es el principio que consiste en agrupar los datos (variables o campos) y los métodos que operan sobre esos datos dentro de una misma unidad (la clase), y restringir el acceso directo a los componentes internos desde el exterior. Su funcion es evitar que el estado interno de un objeto sea modificado de manera incorrecta o inválida por código externo. En su lugar, el objeto expone una interfaz controlada (generalmente a través de propiedades o métodos públicos) para interactuar con él. Su analogía es simple: piensa en un automóvil. El motor, los pistones y el sistema de inyección están encapsulados (ocultos) bajo el capó. Tú no interactúas directamente con los pistones; en su lugar, usas una interfaz controlada: el volante, los pedales y la llave de encendido.

¿Que son los modificadores de acceso?

Los modificadores de acceso son palabras clave que se utilizan para definir la visibilidad o el nivel de acceso que tienen las clases, métodos, propiedades y otros miembros desde otras partes del código o de otros ensamblados (archivos .dll).

Modificadores principales

1. Public: El acceso no está limitado. Se puede acceder al miembro desde cualquier parte del código, incluso desde otros proyectos o ensamblados.

2. Private: El acceso está limitado exclusivamente a la clase en la que se declara. Ninguna otra clase (ni siquiera las herederas) puede verlo ni modificarlo. Es el nivel por defecto para los miembros de una clase (campos y métodos).

3. Protected: El acceso está limitado a la clase contenedora y a cualquier clase que herede de ella (clases derivadas), incluso si están en otros ensamblados.

4. Internal: El acceso está limitado al ensamblaje actual (al proyecto de C# actual). No se puede acceder desde otro proyecto externo, pero sí desde cualquier clase dentro del mismo proyecto.

5. Protected internal: Es una combinación de ambos. El acceso está permitido desde el ensamblaje actual o desde cualquier clase derivada ubicada en otro ensamblaje.

6. Private protected (introducido formalmente en C# 7.2, pero vale la pena mencionarlo como evolución): El acceso se permite únicamente dentro de la clase contenedora o en clases derivadas que estén en el mismo ensamblaje.

¿Para que sirve el encapsulamiento?

1. Garantiza la integridad de los datos: Evita que partes externas del programa modifiquen variables críticas con valores inválidos o erróneos. Por ejemplo, asegura que la edad de una persona nunca sea un número negativo o que un saldo bancario no se altere libremente sin pasar por validaciones.

2. Facilita el mantenimiento y los cambios: Al ocultar los detalles internos de una clase, puedes rediseñar o mejorar su código por dentro sin miedo a que se rompa el resto de la aplicación, siempre y cuando mantengas la misma forma de interactuar con ella desde el exterior.

3. Simplifica el uso del código: Oculta la complejidad innecesaria. Quien use tu clase solo verá los métodos y propiedades que necesita, sin distraerse con variables o funciones auxiliares que operan en segundo plano.

¿Para qué sirven los modificadores de acceso?

Los modificadores son las herramientas exactas con las que construyes ese encapsulamiento, permitiéndote decidir quién puede ver y usar cada parte del código:

1. public (Público): Sirve para exponer al mundo exterior las funciones, propiedades o clases que necesitan ser utilizadas por otras partes del sistema o por otros desarrolladores (como los botones o la interfaz de una máquina).

2. private (Privado): Sirve para blindar y ocultar los datos sensibles y la lógica interna de una clase. Nadie desde afuera puede verlos ni modificarlos, lo que evita errores accidentales. Es el nivel de seguridad más estricto a nivel de clase.

3. protected (Protegido): Sirve para crear una relación de confianza dentro de una familia de clases (herencia). Permite que una clase padre comparta ciertos métodos o variables con sus clases hijas, manteniéndolos ocultos para el resto del programa.

4. internal (Interno): Sirve para proteger el código a nivel de proyecto. Permite que clases o métodos sean visibles entre archivos de tu mismo proyecto o librería de C#, pero evita que otros proyectos o librerías externas los utilicen o dependan de ellos.

Ejemplos

Ejercicio de encapsulamiento

Desarrollar un sistema de gestión para una cuenta bancaria digital en C#. El programa debe garantizar que el saldo del cliente se mantenga protegido de modificaciones directas y erróneas desde fuera de la clase. Toda operación de depósito o retiro debe pasar obligatoriamente por controles de validación lógicos, asegurando montos válidos y fondos suficientes.



    using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;

namespace ConsoleApplication26
{
    class Program
    {
        static void Main(string[] args)
        {
            // Instanciamos la clase CuentaBancaria
            CuentaBancaria miCuenta = new CuentaBancaria();

            // Realizamos operaciones de manera segura a través de los métodos públicos
            miCuenta.Depositar(1000.00);
            miCuenta.Retirar(350.50);

            // Consultamos el saldo final de forma controlada
            Console.WriteLine("El saldo actual en la cuenta es: $" + miCuenta.ObtenerSaldo());

            Console.ReadKey();
        }
    }

    class CuentaBancaria
    {
        // Atributo privado: Nadie fuera de esta clase puede alterarlo directamente
        private double saldo = 0.0;

        // Método público para ingresar dinero con validación previa
        public void Depositar(double monto)
        {
            if (monto > 0)
            {
                saldo += monto;
                Console.WriteLine("Depósito exitoso de: $" + monto);
            }
            else
            {
                Console.WriteLine("El monto a depositar debe ser mayor a cero.");
            }
        }

        // Método público para retirar dinero de forma segura
        public void Retirar(double monto)
        {
            if (monto > 0 && monto <= saldo)
            {
                saldo -= monto;
                Console.WriteLine("Retiro exitoso de: $" + monto);
            }
            else
            {
                Console.WriteLine("Fondos insuficientes o monto inválido.");
            }
        }

        // Método público para consultar el saldo privado
        public double ObtenerSaldo()
        {
            return saldo;
        }
    }
}

Ejercicio de modificadores de acceso

Simular la estructura de datos para un sistema escolar mediante herencia de clases. El programa debe demostrar de forma práctica el uso y alcance de los modificadores de acceso (public, private y protected), comprobando qué variables pueden ser expuestas al programa principal, cuáles permanecen ocultas de forma estricta en su clase, y cuáles se comparten exclusivamente con clases derivadas.



    using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;

namespace ConsoleApplication26
{
    class Program
    {
        static void Main(string[] args)
        {
            // Creamos un objeto de la clase derivada Estudiante
            Estudiante alumno = new Estudiante();

            // 'Nombre' es público, por lo que se puede asignar directamente desde el Main
            alumno.Nombre = "Alejandro";

            // Las siguientes líneas generarían error si se descomentan porque respetan los modificadores:
            // alumno.edad = 20;          // Error: 'edad' es private (solo visible en Estudiante)
            // alumno.calificacion = 19;    // Error: 'calificacion' es protected (no visible desde Main)

            // Usamos el método público para mostrar todos los datos recopilados internamente
            alumno.MostrarDatos();

            Console.ReadKey();
        }
    }

    class Persona
    {
        // Protegido: Accesible dentro de esta clase y en clases que hereden de ella
        protected double calificacion = 18.5;
    }

    // Clase Derivada (Hereda de Persona)
    class Estudiante : Persona
    {
        // Público: Accesible desde cualquier lugar del proyecto
        public string Nombre;

        // Privado: Solo se puede utilizar dentro de la clase Estudiante
        private int edad = 21;

        public void MostrarDatos()
        {
            Console.WriteLine("--- DATOS DEL ESTUDIANTE ---");
            Console.WriteLine("Nombre (Público): " + Nombre);
            Console.WriteLine("Edad (Privado, accedido internamente): " + edad);
            Console.WriteLine("Calificación (Protegido por herencia): " + calificacion);
        }
    }
}
